# Car Rental Management System

A PHP and MySQL based web application for vehicle rental and booking

## Features
- User registration and login
- Vehicle listing and booking
- Admin management
- Booking confirmation and payment flow

## Database Setup
1. Create a database named `vehicle`
2. Import the SQL file from `database/vehicle.sql`
3. Update database credentials in `database.php`

## Technologies Used
- PHP
- MySQL
- HTML, CSS, JavaScript
- XAMPP
